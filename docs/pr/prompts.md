## 2. Постановка задачи

> Давай реализуем эту задачу
>
> Нужно добавить страницу «Управление расписанием» с формой:
> * Поликлиника.
> * Врач выбранной поликлиники.
> * Дата.
> * Начало и окончание рабочего интервала.
> * Необязательный перерыв: начало и окончание.
>
> ## Требования:
> * Запись делится на получасовые слоты. Например, интервал 09:00–11:00 без перерыва даёт четыре слота.
> * Созданные слоты появляются в существующем расписании и доступны для записи.
> * У врача не должно быть пересекающихся интервалов
> * Существующие слоты и записи пациентов сохраняются.
> * Ошибка формы должна объяснять проблему.
>
> Если что-то не однозначно понятно, спрашивай.

## 3. Уточнения, выбранные в диалоге

| Вопрос | Решение |
| --- | --- |
| Как вести работу? | Да, через OpenSpec (SDD) |
| Интервал или перерыв не кратны 30 минутам | Отклонять с пояснением, ничего не создавать |
| Пересечение с существующими слотами врача | Отклонять весь интервал, данные не менять |
| Создание расписания в прошлом | Запретить |
| Выбор врача без JavaScript | Два шага: поликлиника → врачи этой поликлиники |
