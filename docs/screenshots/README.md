# Снимки страниц

- `schedule-form.png` — страница «Управление расписанием» в начальном состоянии, 1600 px.
- `schedule-form-mobile.png` — та же форма при ширине 600 px: поля идут в один столбец,
  горизонтальной прокрутки нет.
- `schedule-created.png` — расписание поликлиники после отправки формы, 1600 px: уведомление
  «Создано слотов: 3» и три новых доступных слота (09:00, 10:00, 10:30 МСК; слот 09:30
  исключён из-за перерыва).

Снимки сделаны на локальном сервере с отдельной временной базой; рабочая база не изменялась.
