# Задание 1. Управление расписанием

## Что добавлено

- Страница `/schedule/new` — «Управление расписанием».
- Выбор поликлиники, врача этой поликлиники, даты, рабочего интервала и необязательного
  перерыва.
- Разбиение интервала на получасовые слоты; перерыв исключается.
- Проверка шага 30 минут, порядка времени, положения перерыва и пересечений с существующими
  слотами врача.
- Атомарное создание слотов: при конфликте не создаётся ничего.
- `POST /api/slots` с теми же правилами.
- Ссылка на управление расписанием из основного расписания и сообщение об успехе.

## Материалы

- `prompts.md` — промпты, с которыми выполнялась задача.
- `schedule-form.png` — заполненная форма управления расписанием.
- `schedule-created.png` — созданные слоты в расписании.
- `schedule-overlap-error.png` — ошибка пересечения с существующим слотом.

Скриншоты сделаны на отдельной временной базе с демонстрационными данными.
