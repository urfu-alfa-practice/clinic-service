# Задание 1. Промпты реализации

Ниже — основные промпты, с которыми выполнялась задача. Ответы на уточняющие вопросы
зафиксированы в разделе «Принятые решения».

## 1. Изучение задания и кода

> Прочитай `tasks/task1.md`, README и относящийся к задаче код. Задай вопросы по
> неоднозначным требованиям перед реализацией: шаг 30 минут, пересечения, прошедшие даты,
> API, дополнительное задание и материалы для PR.

## 2. Принятые решения

- Время, не кратное 30 минутам, отклоняется с понятной ошибкой; неполные слоты не создаются.
- При пересечении с любым существующим слотом врача отклоняется весь запрос, частичных
  изменений нет.
- Расписание можно создавать на любую дату, включая прошедшую.
- Кроме HTML-страницы добавляется `POST /api/slots` с теми же правилами.
- Дополнительное задание OpenSpec пропускается, чтобы не добавлять Node.js в минимальный стек.
- Промпты и скриншоты складываются в `docs/task1/`.

## 3. Модели и правила

> Добавь в `app/models.py` модель `ScheduleCreate` и общий разбор рабочего интервала на
> получасовые слоты. Проверяй шаг 30 минут, порядок начала и окончания, полноту и положение
> перерыва, наличие хотя бы одного слота. Все проверки должны работать и для API, и для HTML.

## 4. Хранилище

> Добавь в `app/repository.py` атомарное создание слотов: проверка поликлиники и врача,
> проверка пересечений с существующими слотами и вставка всех слотов в одной транзакции.
> При конфликте не должно оставаться частично созданных слотов. Существующие слоты и записи
> пациентов не изменяются.

## 5. Интерфейс и API

> Добавь страницу «Управление расписанием» с выбором поликлиники, врача этой поликлиники,
> даты, рабочего интервала и необязательного перерыва. Ошибки формы должны сохранять ввод и
> объяснять проблему. Добавь `POST /api/slots` с теми же правилами и ссылку на управление
> расписанием из существующего расписания.

## 6. Тесты и проверки

> Добавь тесты для разбиения на слоты, перерыва, неверного шага, пересечений, соседних
> интервалов, врача из другой поликлиники, прошедшей даты, API и HTML. Затем выполни
> `python -m pytest`, `python -m ruff check .` и `python -m ruff format --check .`.

## 7. Материалы PR

> Подготовь скриншоты страницы управления расписанием и результата создания слотов,
> сложи их в `docs/task1/`, создай ветку `feature/task1`, закоммить изменения и запушь.
