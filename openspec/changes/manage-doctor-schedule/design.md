## Context

Сервис строит расписание из слотов. Слот может быть занят записью пациента.

## Goals / Non-Goals

Добавлять расписание с перерывом в пределах одного дня по МСК. Редактирование и удаление интервалов в этой задаче не предусмотрены.

## Decisions

- Границы времени должны попадать на `:00` или `:30`. Ввод с неполным слотом отклоняется целиком, чтобы регистратор видел и мог исправить ошибку.
- Смена поликлиники через GET обновляет список врачей без JavaScript. POST проверяет принадлежность врача поликлинике. После сохранения перенаправляю на расписание нужной поликлиники и даты.
- Перерыв необязателен. Если он задан, нужны обе границы строго внутри рабочего интервала. Пересечение проверяется и на время перерыва: новый интервал не может занимать время другого рабочего интервала.
- Храню рабочие интервалы в новой таблице. Существующие данные остаются в прежних таблицах. Проверяю также пересечения с исходными слотами, для которых рабочего интервала в базе нет. Соседние интервалы разрешены.
- Проверка и вставка интервала и всех слотов выполняются в одной транзакции SQLite. При ошибке расписание сохраняется в прежнем состоянии.
- Дата и введённое время интерпретируются в МСК. Сохраняю UTC. Интервал, который уже начался, отклоняется.

## Risks / Trade-offs

Перерыв резервирует время врача внутри интервала. Дополнительная таблица позволяет сохранить это ограничение после перезапуска. Переход на версию 2 создаёт таблицу без переписывания существующих записей.
