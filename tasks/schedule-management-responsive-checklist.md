# Чеклист адаптивности управления расписанием

Проверена страница `/schedule/manage` с демонстрационными данными во встроенном браузере.

- [x] **1280×720**: единая форма занимает одну основную колонку; подсказки находятся у соответствующих полей, правой статической колонки нет.
- [x] **320×812**: пункты меню переносятся на две строки; заголовок, поле поликлиники и кнопка помещаются в видимую область.
- [x] **375×812**: пункты меню переносятся на две строки; заголовок, формы и кнопки остаются доступны без обрезания страницы справа.
- [x] **480×812**: меню и формы помещаются в viewport; попытка горизонтальной прокрутки не сдвигает содержимое.

## Клавиатура

- [x] **Enter в поле начала рабочего интервала**: на полностью заполненной форме выполняется основной `POST /schedule/manage`, возвращается `303` и создаются три слота; вспомогательный GET не вызывается.
